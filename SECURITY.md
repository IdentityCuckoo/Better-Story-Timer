# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | ✅        |
| < 1.0   | ❌        |

## Reporting a Vulnerability

If you find a security issue in the installer, please report it privately via GitHub Issues or Nexus Mods message.

Do not open public issues for security problems.

Include:
- Description of the issue
- Steps to reproduce
- Your Windows version
- Installer version

Thanks for helping keep users safe.
